# AWS E-Commerce Cloud & DevOps Project

An end-to-end AWS E-Commerce application deployed using a highly available 3-tier cloud architecture.

## Project Overview

This project demonstrates the deployment of an E-Commerce application using multiple AWS services, including networking, compute, database, security, load balancing, auto scaling, serverless automation, and monitoring.

## AWS Services

- Amazon VPC
- Amazon EC2
- IAM and Security Groups
- Internet Gateway and NAT Gateway
- Application Load Balancer
- Auto Scaling Groups and Launch Templates
- Amazon RDS MySQL
- AWS Secrets Manager
- Amazon Route 53
- AWS Certificate Manager
- AWS WAF
- Amazon S3 and CloudFront
- AWS Lambda and EventBridge
- Amazon CloudWatch

## Monitoring Tools

- Prometheus
- Grafana
- Node Exporter

## Architecture

8 Subnets across 2 Availability Zones:

- 2 Public Subnets
- 2 Private Frontend Subnets
- 2 Private Backend Subnets
- 2 Private Database Subnets
